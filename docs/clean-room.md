# Clean-room and provenance boundary

SeamScope is a new personal research fixture. Its implementation should remain
traceable to public sources and newly authored code.

## Rules

- Use personally owned hardware and accounts.
- Use only public specifications, public documentation, and compatible
  open-source dependencies.
- Do not copy employer code, schemas, serial commands, protocols, selectors,
  screen designs, test cases, logs, diagrams, or internal terminology.
- Do not describe SeamScope as a recreation of an employer system.
- Record dependency versions and the source of every external protocol or
  requirement used in the research.
- Keep the fixture intentionally fictional and minimal.

This technical provenance discipline does not replace review of any applicable
employment or invention-assignment obligations.
