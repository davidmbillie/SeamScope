# SeamScope v1.0.0 research artifact release

This release packages the reproducible SeamScope fixture and its sanitized
pilot evidence companion for citation alongside the associated Short
Communication.

## Included research object

- React Native Android motion-monitoring application;
- WebdriverIO/Appium automation with injected, Bumble-backed BLE, and physical
  tablet routes;
- Arduino Nano ESP32 serial/BLE fixture firmware;
- frozen `pilot-v1` protocol, run plan, schemas, and disposition record;
- route-relative verdict-and-claim assessment companion;
- normalized records for 88 retained confirmatory attempts;
- manuscript-facing summaries and representative evidence; and
- exact frozen APK and declared firmware binaries.

The 88 retained attempt directories comprise 87 protocol-eligible attempts and
one explicitly retained exclusion. The eligible attempts contain 50 valid
outcomes (49 passes and one valid failure) and 37 invalid pre-stimulus
attempts.

## Release assets

- `SeamScope-v1.0.0-source.tar.gz`: source snapshot generated from tag
  `v1.0.0`;
- `seamscope-v1.0.0-evidence.zip`: sanitized evidence companion; and
- `seamscope-v1.0.0-evidence.zip.sha256`: checksum sidecar.

The evidence archive contains its own README, sanitization policy, package
manifest, structured-record equivalence report, and complete checksum
inventory. Calibration sessions, dry runs, private freeze metadata, unique
hardware serials, machine-specific paths, and incidental nearby Bluetooth
identifiers are excluded.

## Citation and scope

DOI: <https://doi.org/10.5281/zenodo.23903535>

SeamScope is a deliberately small research fixture. It is not an Electronic
Logging Device, ECU emulator, compliance product, or compliance test suite.
The release supports inspection of route-dependent evidence scope; it does not
claim that physical execution is categorically superior to a validated
substitution.
